1. Project Overview
   
MeteoMini is a compact IoT weather station designed for real-time environmental monitoring and data visualization. The system combines an embedded controller, environmental sensors, a local display and a web-based user interface into a single monitoring platform.

The station collects environmental measurements, processes the sensor data and presents the current conditions to the user. Measurements can be viewed directly on the device display or remotely through the web interface.

The software interface is divided into several functional sections, including Dashboard, Weather, History, Settings and About. This structure allows the user to monitor current conditions, review previously collected data and configure the system.

MeteoMini also supports different display modes, including a dedicated Night Mode for more comfortable operation in low-light conditions. The project was designed as a modular system, allowing additional functionality and sensors to be integrated in the future.
